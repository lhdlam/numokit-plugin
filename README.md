# numokit-plugin

Claude Code plugin marketplace for **numokit** — AI dev toolkit.

Agent phân tích & sửa code, lập trình viên gác cổng. Mọi thao tác chạm code đều dừng ở một human gate.

```
/plugin add marketplace github:lhdlam/numokit-plugin
/plugin install numokit@lhdlam-numokit
```

Chi tiết: [plugins/numokit/README.md](plugins/numokit/README.md).
